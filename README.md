# 🌐 Swap Hub — платформа для обмена вещами

Проект представляет собой платформу для обмена вещами среди пользователей. <br>
__Основная цель__ — обеспечение удобной организации бартера, позволяющей пользователям размещать объявления о вещах, предлагать обмен и взаимодействовать друг с другом через веб-интерфейс и API.

### ⚙️ Технологический стек
Язык программирования: Python 3.8+ <br>
Веб-фреймворк: Django 4.x <br>
Система шаблонов: Django Templates <br>
Базы данных: SQLite (для разработки)/ PostgreSQL (рекомендуется для продакшена)
REST API: Django REST Framework (опционально) <br>
Управление зависимостями: Poetry <br>
Тестирование: Unittest <br>

### 📖 Функциональные требования
__Основные возможности платформы:__ <br>
Создание объявления: Пользователь создает новое объявление с указанием заголовка, описания, состояния вещи, фотографии и категорий. <br>
Редактирование объявления: Автор может изменять свое объявление, но никто другой не вправе вносить изменения. <br>
Удаление объявления: Удаляет объявление по его уникальному идентификатору. <br>
Поиск и фильтрация объявлений: Возможности поиска по названию и описанию вещей, фильтрация по категориям и состоянию товаров. <br>
Работа с предложениями обмена: Отправка предложений обмена, просмотр текущих предложений, принятие или отклонение предложений. <br>

### 🛠 Установка и настройка окружения
Предварительные требования: <br>
Установленный Python версии >= 3.8 <br>
Git <br>
Poetry (рекомендован для управления зависимостями) <br>

### Инструкция по установке:
Клонируйте репозиторий проекта:
``````
git clone https://github.com/Nurlan-Grachyov/SwapHub.git
cd SwapHub
``````
Установите Poetry (если еще не установлено):
````
curl -sSL https://install.python-poetry.org | python -
export PATH="$HOME/.local/bin:$PATH"
````
Активируйте виртуальное окружение и установите зависимости проекта:
````
poetry shell
poetry install
````

### 💾 Настройка баз данных
По умолчанию проект настроен на использование SQLite. Для локальных разработок это подходящий вариант. Если планируете развернуть проект на производственном окружении, рекомендуется переключиться на PostgreSQL.

### Локальная база данных (SQLite):
Нет необходимости в специальной конфигурации, Django автоматически создаст базу данных SQLite в папке проекта.

__Продакшн база данных (PostgreSQL):__ <br>
Убедитесь, что PostgreSQL установлен и запущен. <br>
Создайте новую базу данных и пользователя с правами администратора. <br>
Откройте файл настроек проекта (settings.py) и укажите правильные настройки подключения к базе данных: <br>
````
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': '<название_базы>',
        'USER': '<имя_пользователя>',
        'PASSWORD': '<пароль>',
        'HOST': 'localhost',
        'PORT': '',
    }
}
````
### ✨ Запуск миграций
Перед запуском сервера выполните миграции для создания таблиц в базе данных:

````
python manage.py makemigrations
python manage.py migrate
````
### 🚀 Запуск сервера
Запустите локально Django-сервер командой:

````
python manage.py runserver
````
Сервер запустится по адресу http://127.0.0.1:8000/.

### 🔍 Доступ к административному интерфейсу
Чтобы управлять пользователями и объявлениями через административный интерфейс Django, создайте суперпользователя:

````
python manage.py createsuperuser
````
Затем перейдите по ссылке /admin/ и войдите с учетными данными суперпользователя.

### 🧩 Запуск тестов
Для запуска модульных тестов используйте команду:

````
python manage.py test
````

### 🗂 Документация API
Если вы решили использовать Django REST Framework, документацию API можно получить автоматически через интерфейс Browsable API, доступный по адресу /api/docs/.
